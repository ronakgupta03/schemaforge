# users-split Example

This directory contains the deterministic fixture for the **users-split migration** — the primary example used to develop and demonstrate SchemaForge.

## Scenario

Split a monolithic `users` table into two focused tables:

| Source table | Target table | Fields moved |
|---|---|---|
| `users` | `user_accounts` | `id`, `email`, `password_hash`, `created_at` |
| `users` | `user_profiles` | `user_id` (FK), `display_name`, `avatar_url`, `bio`, `updated_at` |

## Directory structure

```
users-split/
├── schema.sql          ← DB schema: monolithic source table + TODO target tables
├── models/
│   └── user.ts         ← ORM model (pre-migration)
├── dao/
│   └── user-dao.ts     ← DAO interface + raw SQL queries (AST scan targets)
├── services/
│   └── user-service.ts ← Service interface (pre-migration)
└── tests/
    └── user-split.test.ts ← Fixture test + pending integration test list
```
